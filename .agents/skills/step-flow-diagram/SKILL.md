# 단계형 흐름 다이어그램 생성

사용자가 준 단계 목록을 JSON으로 정리해 `scripts/diagram_gen.py`로 깔끔한 다이어그램(SVG + PNG)을 만든다. 스타일은 고정이다: 흰 바탕, 슬레이트 계열 박스, 강조는 레드 하나, 거의 직각 모서리, 번호 매기기 없음, 그림자·그라데이션·아이콘 없음.

## 작업 순서

1. 사용자가 준 내용에서 묶음(phase), 단계(step), 강조할 단계, 외부 대상을 정리한다. **내용을 임의로 추가하거나 바꾸지 않는다.** 내용이 없으면 먼저 단계 목록을 요청한다.
2. 입력 JSON(`내용.json`)을 작성한다. 형식은 아래 또는 `references/sample.json` 참고.
3. 실행한다: `python3 scripts/diagram_gen.py 내용.json 출력폴더` (스킬 폴더 기준 경로. 기본은 `--layout auto`)
4. 생성된 PNG를 직접 열어 글자 넘침, 겹침, 한글 깨짐, 강조 단계가 맞는지 확인한다. 스크립트가 "주의:" 경고(말줄임 처리)를 출력하면 단계명·설명을 줄여 달라고 하거나 짧게 다듬은 안을 제안한다.
5. PNG와 SVG를 사용자에게 전달한다. 위키에는 PNG, 색·글꼴 수정은 SVG를 쓰면 된다고 한 줄로 안내한다.

## 레이아웃 자동 선택

- `groups`(묶음형): 묶음 4개 이하, 묶음당 6단계 이하이고 글자가 박스를 넘치지 않을 때. 묶음을 박스로 나눠 세로로 쌓는다.
- `table`(표형): 그 외 내용이 많을 때. 구분/동작/상세 표에 타임라인을 붙인다. 단계 수 제한이 없다.
- 강제 지정: `--layout groups|table|both`. 사용자가 둘 다 보고 싶어 하면 `both`.

## 입력 형식

```json
{
  "title": "다이어그램 제목",
  "phases": [
    {"name": "묶음 이름", "steps": [
      {"name": "단계명", "desc": "한 줄 설명"},
      {"name": "강조할 단계", "desc": "설명", "hl": true}
    ]}
  ],
  "external": {"name": "외부 대상", "desc": "설명"}
}
```

- `hl: true`인 단계가 레드로 강조된다 (여러 개 가능). 강조색은 레드 하나로 고정이며 바꾸지 않는다.
- `external`은 선택이다. 마지막 묶음 아래 점선 박스(묶음형) 또는 마지막 점선 행(표형)으로 표시된다.
- 단계명은 짧은 명사형(예: 실행, C2 접속), 설명은 한 줄 12~16자 정도가 좋다. `desc`는 생략할 수 있다.

## 주의

- PNG 변환에는 `rsvg-convert`와 한글 폰트가 필요하다. `fc-list :lang=ko`로 한글 폰트를 확인하고, 없거나 `rsvg-convert`가 없으면 SVG만 전달하며 그 사실을 알린다.
- 스타일(색, 모서리, 폰트)을 바꾸려면 `scripts/diagram_gen.py` 상단의 색상 상수를 수정한다.
